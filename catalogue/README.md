# LOADED Product Catalogue Source

This folder contains the structured source for the A.G. Manufacturing and Trading Pvt. Ltd. LOADED product catalogue.

## Structure

- `data/products.json` - price-free SKU, grade, use and pack-size data.
- `assets/brand/` - supplied A.G. Manufacturing and LOADED logos.
- `assets/products/` - selected, locally optimized product pack shots.
- `assets/generated/` - generated 200 L industrial drum mockup; the original LOADED mark is overlaid during PDF composition.
- `src/build_catalogue.py` - deterministic ReportLab catalogue builder.
- `../output/pdf/AG-Manufacturing-LOADED-Product-Catalogue.pdf` - final catalogue.

The catalogue intentionally excludes prices. Product naming and specifications are based on the supplied SKU sheet dated Bhadra 01, 2083. Confirm the latest technical data sheet and equipment manufacturer recommendation before critical use.
